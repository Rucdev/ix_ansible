Synopsis

Notes
-----

.. note::
   - Tested against NEC IX version 10.10.29 on IX 2215.
   - This module works with connection ``network_cli``.
   - The hostname must not contain whitespace. IX accepts ``hostname a b`` without error but stores only ``a``, so the module rejects such values.
   - Since hostname is a single value, ``merged``, ``replaced`` and ``overridden`` behave the same.
   - ``deleted`` sends ``no hostname``, which removes the ``hostname`` line from the running-config.



Examples
--------

.. code-block:: yaml

    # Using merged

    # Before state:
    # -------------
    # Router(config)# show running-config
    # (no hostname line)

    - name: Set hostname
      rucdev.ix.ix_hostname:
        config:
          hostname: Router1
        state: merged

    # Commands sent:
    # - hostname Router1

    # Using deleted

    # Before state:
    # -------------
    # Router1(config)# show running-config
    # hostname Router1

    - name: Remove hostname
      rucdev.ix.ix_hostname:
        state: deleted

    # Commands sent:
    # - no hostname

    # Using gathered

    - name: Gather hostname
      rucdev.ix.ix_hostname:
        state: gathered

    # Task Output:
    # gathered:
    #   hostname: Router1

    # Using rendered

    - name: Render the commands for provided configuration
      rucdev.ix.ix_hostname:
        config:
          hostname: Router1
        state: rendered

    # Task Output:
    # rendered:
    #   - hostname Router1

    # Using parsed

    - name: Parse the provided configuration
      rucdev.ix.ix_hostname:
        running_config: |
          hostname Router1
        state: parsed

    # Task Output:
    # parsed:
    #   hostname: Router1
