Examples
--------

.. code-block:: yaml

    - name: Configure hostname
      rucdev.ix.ix_config:
        lines: hostname {{ inventory_hostname }}

    - name: Configure GigaEthernet interface
      rucdev.ix.ix_config:
        lines: ip address 192.168.1.1/24
        parents:
          - interface GigaEthernet0.0
