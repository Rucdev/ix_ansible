Notes
-----

.. note::
   - Tested against NEC IX2215 Version 10.8.21.
   - This module works with connection network_cli.



Examples
--------

.. code-block:: yaml

    - name: Example device_interface module
      rucdev.ix.device_interface:
        config:
          name: GigaEthernet0
          duplex: full
          speed: auto
